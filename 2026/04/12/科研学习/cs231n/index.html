import numpy as np

class NearestNeighbor:
    def __init__(self):
        """
        构造函数，在这个简单的模型中不需要做任何初始化。
        """
        pass

    def train(self, X, y):
        """
        训练模型。对于最近邻算法，"训练" 过程仅仅是记住所有的训练数据。
        - X: 训练数据特征，形状为 (N, D)，N是样本数量，D是特征维度。
        - y: 训练数据标签，形状为 (N,)。
        """
        # the nearest neighbor classifier simply remembers all the training data
        self.Xtr = X  # 存储训练样本特征 这些类的属性不用像C++一样单独初始化
        self.ytr = y  # 存储训练样本标签

    def predict(self, X):  # self在外面，不用单独写传入，这里代之类自己
        """
        对新的数据 X 进行预测。
        - X: 测试数据特征，形状为 (num_test, D)，num_test 是测试样本数量。
        """
        num_test = X.shape[0]
        # 创建一个和测试样本数量相同大小的数组来存放预测结果
        Ypred = np.zeros(num_test, dtype=self.ytr.dtype)  # dypte是数组元素的类型

        # 遍历每一个测试样本
        for i in range(num_test):
            # 计算第 i 个测试样本与所有训练样本之间的距离
            # 这里使用的是 L1 距离 (曼哈顿距离)
            # L1 distance = sum(|x1 - x2|)
            distances = np.sum(np.abs(self.Xtr - X[i,:]), axis=1)   
            # 这里对于每一个X[i,:] 都把训练数据遍历一遍
            
            # 找到距离最小的那个训练样本的索引
            min_index = np.argmin(distances)
            
            # 将距离最近的训练样本的标签作为当前测试样本的预测标签
            Ypred[i] = self.ytr[min_index]
            
            # 打印进度（可选，用于调试或观察）
            if i % 100 == 0:
                print(f"Processed {i}/{num_test} test samples.")

        return Ypred

# k阶最邻近算法

这里先介绍一下分类问题和回归问题：

分类问题和回归问题是监督学习中的两种基本类型，它们的区别在于 输出变量（标签） 的性质不同：

分类问题是对样本进行一个分类，回归问题是基于已有的样本数据，对未来的数据进行一个预测（这属于连续性的输出）, 常见如线性回归等。

对于过拟合和欠拟合，过拟合当模型对训练数据的拟合太好，以至于它也过度学习了数据中的噪声、异常值或不必要的细节时，就会发生过拟合。此时，模型在训练集上的表现非常好，但在测试集或新数据上的表现较差，无法泛化到新的数据。

**欠拟合（Underfitting）**是指当模型过于简单，无法捕捉到数据中的潜在规律时，发生欠拟合。模型无法在训练集上获得足够的学习，导致训练和测试集的表现都很差。

在 KNN（k-最近邻） 算法中，k 值是一个重要的超参数，表示选择 k 个最近邻 来进行预测。如果训练数据中包含噪声（例如，错误的标签或异常值），最近的一个邻居可能正好是噪声，那么预测结果就会受到噪声的影响。举个例子，假设在一个二维平面上，测试样本的位置靠近一个异常的训练样本，而这个异常样本的标签可能是错误的。那么，k=1 会把这个异常样本的标签作为预测结果，导致 错误的预测。与此相反，当k较大的时候，我们就可以减少噪声造成的影响。

# liner classifier

在 k-NN 中，我们没有训练过程，预测时需要拿新图片和所有训练图片比对。这太慢了。
线性分类器引入了参数 (Parameters) 的概念：我们将训练数据的知识总结到了权重矩阵 WWW 中，训练完后，训练数据就可以扔掉了。

公式为：$$f(x, W) = Wx + b$$

其中：

  • xxx (Input): 输入图像。
    • 例如图像是 32×32×332 \times 32 \times 332×32×3 的。我们需要先把它拉平 (Flatten) 成一个长向量。
    • 维度 D=32×32×3=3072D = 32 \times 32 \times 3 = 3072D=32×32×3=3072。所以 xxx 是一个 [3072×1][3072 \times 1][3072×1] 的列向量。
  • WWW (Weights): 权重矩阵。
    • 这是我们要“学习”的参数。
    • 如果有 K=10K=10K=10 个分类（猫、狗、船等），WWW 的维度就是 [10×3072][10 \times 3072][10×3072]。
  • bbb (Bias): 偏置项。
    • 不管输入是什么，某些类别可能本身就更容易出现（先验概率），bbb 负责微调。维度是 [10×1][10 \times 1][10×1]。
  • fff (Scores): 输出分数。
    • 计算结果是一个 [10×1][10 \times 1][10×1] 的向量，代表该图片属于这 10 个类别的“得分”。得分越高，分类器越确信它是这一类。

从代数求和角度看，线性分类器就像是在做加权。对于“猫”这个类别，分类器会查看输入图像的每一个像素。如果某个像素位置通常是黄色的（比如猫的眼睛），WWW 中对应位置的权重就会是正数（加分）。如果某个位置通常是蓝色的（比如天空，不太可能出现在猫身上），权重可能是负数（扣分）。最后加上 bbb（比如如果数据集里猫特别多，猫的 bbb 就大一点，起跑线高一点）。

从视觉角度来看，WWW 的每一行实际上就是一个类别的“平均模板” (Prototype)。计算 WxWxWx 实际上是在计算输入图像 xxx 和这 10 个模板的相似度（点积 Dot Product）。

从集合视角来看，这是一个高维空间（3072 维的空间）。每一个输入图像 xxx 是这个空间里的一个点。线性分类器 Wx+b=0Wx + b = 0Wx+b=0 实际上是在这个空间里切了一刀（定义了一个超平面 Hyperplane）。对于“汽车”这一类，这个平面把空间分成了两半：一边是“汽车”，一边是“非汽车”。

如果没有 bbb ，平面一定经过原点，加入后我们就可以随意地移动平面，这样能更好地拟合数据。

但比如一些多模态的数据和线性不可分的数据，线性分类器并不好处理。

这里有三种正则化函数：

  • L2 正则化 (L2 regularization): R(W)=∑W2R(W) = \sum W^2R(W)=∑W2，即将权重矩阵 W 中每一个元素都平方，然后求和。它倾向于让所有的权重都比较小，但不会让它们完全等于0（平方之后就更小了）。这会使得模型的决策边界更平滑，降低了模型对个别特征的依赖，从而提高了泛化能力。它也被称为“权重衰减 (Weight Decay)”。

  • L1 正则化 (L1 regularization): R(W)=∑∣W∣R(W) = \sum |W|R(W)=∑∣W∣，将权重矩阵 W 中每一个元素的绝对值求和。L1正则化有一个非常重要的特性，它会促使很多权重变为0。这相当于让模型自动进行“特征选择”，只保留那些最重要的特征（权重不为0的），而忽略掉不重要的特征（权重为0的），从而得到一个稀疏模型 (Sparse Model)。

策略3：梯度下降

在上策略中，我们试图在权重空间中找到一个能改善我们的权重向量（并使损失降低）的方向。事实证明，没有必要随机搜索一个良好的方向：我们可以计算最佳方向，沿着这个方向我们应该改变我们的权重向量，这在数学上是保证是最速下降方向（至少在步长趋于零的极限中）。这个方向将与损失函数的梯度相关。在我们的登山类比中，这种方法大致对应于感受我们脚下小山的坡度，并沿着感觉最陡峭的方向向下走。

# RMSProp

以上的动量法存在一些问题：在普通 SGD 或 Momentum 中，所有参数的更新步长都由同一个 learning_rate 控制。但实际训练时，不同参数的梯度变化幅度差别很大：有的维度梯度一直很大，有的维度梯度一直很小。如果用同一个学习率，梯度大的维度容易 “走过头”（震荡），梯度小的维度又 “走太慢”（收敛慢）。

grad_squared = 0
while True:
    dx = compute_gradient(x)  # 1. 算出当前参数的梯度
    grad_squared = decay_rate * grad_squared + (1 - decay_rate) * dx * dx  # 2. 核心累积
    x -= learning_rate * dx / (np.sqrt(grad_squared) + 1e-7)  # 3. 自适应更新

  • grad_squared 是一个 “记忆体”，保存着从训练开始到现在，每个维度梯度平方的加权平均。

  • decay_rate（通常取 0.9）决定了 “记忆” 的权重：它越大，越依赖历史值；越小，越依赖当前值。

  • dx * dx 是当前梯度的平方，用来衡量当前梯度的 “波动幅度”。

  • 第2步记录每个维度梯度的历史波动大小。波动大的维度，grad_squared 会变大；波动小的维度，grad_squared 会变小。

  • np.sqrt(grad_squared) 就是 “梯度的均方根”（Root Mean Square），这也是 RMSProp 名字的来源。

  • dx / np.sqrt(grad_squared) 就是用历史波动幅度来缩放当前梯度：

    • 如果 grad_squared 大（历史波动大）→ 分母大 → 步长自动变小。
    • 如果 grad_squared 小（历史波动小）→ 分母小 → 步长自动变大。

  • + 1e-7 是为了防止分母为 0，避免计算错误。

# Adam

这是现在最常用的优化器，它结合了Momentum和RMSProp。

first_moment = 0    # 一阶动量（对应Momentum的累积梯度）
second_moment = 0   # 二阶动量（对应RMSProp的梯度平方累积）
while True:
    dx = compute_gradient(x)  # 计算当前梯度
    # 1. 更新一阶动量（类似Momentum的累积）
    first_moment = beta1 * first_moment + (1 - beta1) * dx
    # 2. 更新二阶动量（类似RMSProp的梯度平方累积）
    second_moment = beta2 * second_moment + (1 - beta2) * dx * dx
    # 3. 结合一阶和二阶动量做更新
    x -= learning_rate * first_moment / (np.sqrt(second_moment) + 1e-7)

但是在初始步骤也可能遇到二阶动量非常接近于0的情况（由于开始的时候second_moment为0）所以这时后我们要处理一下，所以

first_moment = 0
second_moment = 0
for t in range(1, num_iterations):  # t是当前迭代次数，从1开始
    dx = compute_gradient(x)
    # 一阶动量（来自Momentum）
    first_moment = beta1 * first_moment + (1 - beta1) * dx
    # 二阶动量（来自RMSProp）
    second_moment = beta2 * second_moment + (1 - beta2) * dx * dx
    # 偏差修正，随着t的增加，beta**t也会趋近于0，修正项的偏差也会逐渐减小
    first_unbias = first_moment / (1 - beta1 ** t)
    second_unbias = second_moment / (1 - beta2 ** t)
    # 参数更新（结合了Momentum的方向和RMSProp的自适应步长）
    x -= learning_rate * first_unbias / (np.sqrt(second_unbias) + 1e-7)

# 初始化权重
w1, w2 = randn(D_in, H), randn(H, D_out)

# 训练循环
for t in range(2000):
    # 前向传播
    h = 1 / (1 + np.exp(-x.dot(w1)))   # sigmoid：选用上图的第四个
    y_pred = h.dot(w2)

    # 计算损失
    loss = np.square(y_pred - y).sum()  # 损失函数使用均方误差MSE：Loss = Σ (y_pred - y)^2
    print(t, loss)

    # 反向传播（手推梯度）
    grad_y_pred = 2.0 * (y_pred - y)   # 对y求导
    grad_w2 = h.T.dot(grad_y_pred) 	 # 链式法则求导，下面同理，推导感兴趣自己推
    grad_h = grad_y_pred.dot(w2.T)
    grad_w1 = x.T.dot(grad_h * h * (1 - h))

    # 梯度下降更新参数
    w1 -= 1e-4 * grad_w1
    w2 -= 1e-4 * grad_w2

# 反向传播

就是链式法则逐层往回求导，其实上面都涉及到了。多层神经网络也是这样一层层求导下去，调整参数。

这样我们就可以定义一个API来实现反响传播的模块。

总的来说就是：

  • Scalar → Scalar（标量到标量），线性的x变一点，y变多少
  • Vector → Scalar（向量到标量）

​ x∈RN,y∈Rx \in \mathbb{R}^N, y \in \mathbb{R}x∈RN,y∈R 导数变成： $$ \frac{\partial y}{\partial \mathbf{x}} = \begin{bmatrix} \frac{\partial y}{\partial x_1} \ \frac{\partial y}{\partial x_2} \ \vdots \ \frac{\partial y}{\partial x_N} \end{bmatrix} $$

  • Vector → Vector（向量到向量）

    x∈RN,y∈RMx \in \mathbb{R}^N, y \in \mathbb{R}^Mx∈RN,y∈RM 导数变成矩阵： $$ \frac{\partial \mathbf{y}}{\partial \mathbf{x}} = \begin{bmatrix} \frac{\partial y_1}{\partial x_1} & \cdots & \frac{\partial y_1}{\partial x_N} \ \vdots & \ddots & \vdots \ \frac{\partial y_M}{\partial x_1} & \cdots & \frac{\partial y_M}{\partial x_N} \end{bmatrix} $$ 这就是： 雅可比矩阵（Jacobian）

但是如果输入输出很大的话，这个乘起来就会让Jacobian很大，于是我们根本不构造这个矩阵，直接通过链式法则计算乘积。反向传播，这样会小很多。

VGGNet（2014）是一个结构非常规整的卷积神经网络，核心思路是用多个小的 3×33\times33×3 卷积层不断堆叠来加深网络（如VGG16、VGG19），中间穿插池化层，最后接全连接层做分类。它的优点是结构简单、易理解，特征提取能力强，但缺点是参数量很大、计算开销高，训练成本较高，也容易过拟合。

ResNet（2015）在此基础上引入了“残差连接”（skip connection），通过让输出变为 y=F(x)+xy=F(x)+xy=F(x)+x，使网络学习残差而不是直接映射，从而解决深层网络训练中的退化问题。这样可以构建非常深的网络（如ResNet50/101/152）且更容易训练，性能也通常优于VGG，是现代深度网络的重要基础结构。

更深的网络往往更难优化

# 如何初始化

我们不能把值初始化的太大，否则会越来越大。

dims = [4096] * 7
hs = []
x = np.random.randn(16, dims[0])

for Din, Dout in zip(dims[:-1], dims[1:]):
    W = np.random.randn(Din, Dout) * np.sqrt(2 / Din)
    x = np.maximum(0, x.dot(W))
    hs.append(x)

这是一个很厉害的人提出的，感兴趣可以看看论文。出先用标准正态分布随机初始化权重，再乘上一个缩放因子 2/Din\sqrt{2/D_{in}}2/Din​​

因为如果不做缩放，随着层数加深：

  • 前向传播时，数值会越来越大或越来越小（爆炸/消失）
  • ReLU 会让一半神经元变成 0，加剧这个问题

He 初始化的作用：

  • 让每一层输出的方差保持稳定
  • 特别适合 ReLU 激活函数
  • 保证信号在深层网络中“不过大也不过小”

# 概述

循环神经网络如上：

RNN 用同一个函数 (f) 在时间序列上反复处理数据：

ht,yt=f(ht−1,xt)h_t, y_t = f(h_{t-1}, x_t) ht​,yt​=f(ht−1​,xt​)

组成：

  • 输入 ( x_t )：序列中的当前元素
  • 隐状态 ( h_t )：累计“记忆”（上下文信息）：ht=f(ht−1,xt)h_t= f(h_{t-1}, x_t)ht​=f(ht−1​,xt​)
  • 输出 ( y_t )：当前时刻的输出 ，这里直接取决于 $ y_t = f_{W_{hy}}(h_{t}) $
  • 函数 (f)：共享参数的网络（每一步都一样）
h0 + x1 → f → h1 → y1
h1 + x2 → f → h2 → y2
h2 + x3 → f → h3 → y3

就是每一步的状态来自于上一步的状态和当前的输出。

# 梯度下降

关于如个计算，这个只是可以看成一个非常深的神经网络，只是他们的参数是一样的。

梯度下降，也是从后往前进行传播

∂L∂ht=∂Lt∂ht+∂L∂ht+1⋅∂ht+1∂ht\frac{\partial L}{\partial h_t} = \frac{\partial L_t}{\partial h_t} + \frac{\partial L}{\partial h_{t+1}} \cdot \frac{\partial h_{t+1}}{\partial h_t} ∂ht​∂L​=∂ht​∂Lt​​+∂ht+1​∂L​⋅∂ht​∂ht+1​​

  • 第一项：当前时间步的误差
  • 第二项：来自未来时间步的误差

然后每个时间步都会产生对 WWW 的梯度：

∂L∂W=∑t∂Lt∂W\frac{\partial L}{\partial W} = \sum_t \frac{\partial L_t}{\partial W} ∂W∂L​=t∑​∂W∂Lt​​

最后统一更新一次参数：

W=W−η∂L∂WW = W - \eta \frac{\partial L}{\partial W} W=W−η∂W∂L​

# 门

这里引入了四个门，其实长的一样，只是权重不同：

gate=σ(W[xt,ht−1]+b)\text{gate} = \sigma(W [x^t, h^{t-1}] + b) gate=σ(W[xt,ht−1]+b)

  • 忘记门（Forget Gate）

zf=σ(Wf[xt,ht−1]+bf)z^f = \sigma(W^f [x^t, h^{t-1}] + b^f) zf=σ(Wf[xt,ht−1]+bf)

控制：旧记忆 ct−1c^{t-1}ct−1 保留多少？0就是全忘记，1就是保留，当然这个取值是[0-1]

  • 输入门（Input Gate）

zi=σ(Wi[xt,ht−1]+bi)z^i = \sigma(W^i [x^t, h^{t-1}] + b^i) zi=σ(Wi[xt,ht−1]+bi)

控制：“要不要写入新信息？” 也是0不写1写

  • 候选记忆（Candidate）

z=tanh⁡(W[xt,ht−1]+b)z = \tanh(W [x^t, h^{t-1}] + b) z=tanh(W[xt,ht−1]+b)

控制“要写入的内容是什么？”

这个不是开关，控制的是内容，决定些什么

  • 输出门（Output Gate）

zo=σ(Wo[xt,ht−1]+bo)z^o = \sigma(W^o [x^t, h^{t-1}] + b^o) zo=σ(Wo[xt,ht−1]+bo)

控制：“当前记忆要输出多少？” 也是0输出1不输出

# 架构

核心公式 ：

  • 记忆更新：

ct=zf⊙ct−1+zi⊙zc^t = z^f \odot c^{t-1} + z^i \odot z ct=zf⊙ct−1+zi⊙z

  • 输出隐状态：

ht=zo⊙tanh⁡(ct)h^t = z^o \odot \tanh(c^t) ht=zo⊙tanh(ct)

  • 最终输出：

yt=σ(W′ht)y^t = \sigma(W' h^t) yt=σ(W′ht)

这个圈点的意思是逐元素相乘。

如上图，我们用 c 来保留长期记忆，用 h 来代表短期记忆。所以 c 使用加法进行更新，h 使用乘法进行更新。这样前者的变化可以较慢。

transformers基本是现在所有模型都用的。

我们首先看这个RNN，比如一个问题：我们从英语翻译成意大利语，

我们不能确定这些词的关系、顺序、数量。所以用RNN处理这个可以追溯到2014年。

通常我们从一个encoder开始，它是一个循环神经网络。这样输出一个总结的内容。（总结一下输入的东西成为一个词向量，成为上下文词向量。

所以最终的输出必须包含输入序列的所有信息。所以我们进一步使用一个decoder，它也是一个循环神经网路，使用不同的参数。

不过这个decoder的输入不只是x和隐藏状态了，它有三个：

  • 上一个时刻的输出，记作：yt−1y_{t-1}yt−1​

  • 上一个隐藏状态：记作：st−1s_{t-1}st−1​，用来传递序列信息（类似 encoder 的 $ h_t $）

  • 上下文向量（Context vector），记作：ccc，来自 encoder

但是这里存在一个问题，因为encoder和decoder的连接只依靠一个c，这个c是固定大小的，如果我们做一个短序列，这样可以，但是我们如果翻译一本书的话，就很不合理。要一个向量记住整本书肯定不明智。

所以这里我们的解决方案不是打破平静，我们的方法是改变架构：给模型会回看相关内容的能力。

Cross-Attention（交叉注意力）*的核心目的是*实现两个不同信息源之间的信息融合与对齐。与 Self-Attention（自我理解）不同，在这里，Query（查询需求）来自目标序列（例如正在生成的翻译结果或特定任务的提示），而 Key 和 Value（知识库）来自另一个源序列（例如原文或外部数据库）。计算相似度分数的过程，本质上是目标序列在“跨界”向源序列提问：“为了完成我当前的任务，我应该把注意力集中在你的哪些部分？”。通过算出的高分权重提取对应的 Value，就能实现带着特定目的去另一个数据库里精准“进货”**的效果（常用于机器翻译的源-目标对齐、图像描述生成中的图文对齐等）。

这个常应用于翻译的场景。
