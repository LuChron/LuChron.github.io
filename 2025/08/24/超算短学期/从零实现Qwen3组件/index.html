# 1 实验简介

本实验通过从零实现 Qwen3-8B 模型中的关键组件来掌握深度学习的核心概念。你将亲手实现 Self Attention 和 Feed Forward Network (FFN)，最终构建一个完整的语言模型，并在此基础上进行文本生成。

在本实验中，你将学习并实践以下内容：

  • 深入理解 Transformer 架构中的 Self Attention
  • 掌握前馈神经网络 (FFN) 和 SwiGLU 激活函数的实现
  • 了解分组查询注意力 (Grouped Query Attention, GQA) 优化方法
  • 在实践中理解 LLM 的推理过程

# 2 知识讲解：Qwen3 Model Architecture

Qwen3 采用标准的 Transformer Decoder 架构，其推理过程如下：

  1. Tokenization：将输入文本转换为 token 序列，每一个 token 对应一个整数 ID。这一部分由 Tokenizer 完成。
  2. Embedding：将 token ID 转换为高维向量表示。这一部分由 Embedding 层完成。
  3. Decoder Layers: 将输入向量依次通过多个解码器层，每层包含以下组件：
  4. Multi-Head Attention (MHA)：计算输入 token 之间的注意力分数。
  5. Feed Forward Network (FFN)：对每个 token 的表示进行非线性变换。
  6. Layer Normalization：对每层的输出进行归一化处理。
  7. Output Layer：将最后一层的输出通过线性变换和 softmax 层转换为 token ID 的概率分布。
  8. Text Generation：根据概率分布生成下一个 token，并将 token 放入 token 序列中。重复步骤 2-4 直到生成结束标志。

<img src="/assets/图片/qwen3_arch.png" alt="Qwen3 模型架构示意图" style="zoom:33%;" />

Qwen 3 在标准 Decoder-Only 架构的基础上，采用了以下优化：

  • 分组查询注意力 (Grouped Query Attention, GQA)：通过共享 Key/Value 头来减少计算量。
  • RoPE (Rotary Position Embedding)：使用旋转位置编码来增强模型对序列位置的感知。
  • Q/K Normalization：在计算注意力分数之前，对 Query 和 Key 进行归一化处理。
  • RMSNorm：使用 RMSNorm 替代 LayerNorm 进行归一化处理。
  • SwiGLU 激活函数：使用 SwiGLU 作为前馈网络的激活函数，增强模型的表达能力。

在本次实验中我们使用的是 Qwen3-8B 模型，其关键参数如下：

参数 值 参数含义
num_hidden_layers 36 Decoder Layer 数量
hidden_size 4096 每层的隐藏层维度
num_attention_heads 32 注意力头数量
num_key_value_heads 8 Key/Value 头数量 (用于 GQA)

# 3 Self Attention Layer 详解

# 3.1 注意力机制原理

注意力机制的核心思想是让模型在处理每个位置的token时，能够关注到序列中的所有相关位置。数学公式如下：

Attention(Q,K,V)=softmax(QKT+maskdk)V\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T + \text{mask}}{\sqrt{d_k}}\right)V Attention(Q,K,V)=softmax(dk​​QKT+mask​)V

其中：

  • Q (Query)：查询矩阵，形状为 [batch_size, seq_len, d_model]
  • K (Key)：键矩阵，形状为 [batch_size, seq_len, d_model]
  • V (Value)：值矩阵，形状为 [batch_size, seq_len, d_model]
  • mask：掩码矩阵，形状为 [batch_size, seq_len, seq_len]
  • dkd_kdk​：Key的维度，用于缩放
  • batch_size：一个 batch 的大小
  • seq_len：序列长度
  • d_model：模型的隐藏层维度

在我们的实验中，由于 LLM 是依赖前面的 token 来预测下一个 token 的过程，因此我们需要使用 Causal Mask（因果掩码）来确保模型只能看到当前 token 之前的 token。Causal Mask 的常见实现方式是将上三角部分设置为负无穷大，这样在 softmax 计算时，这些位置的注意力分数会被归一化为 0。

# 3.2 多头注意力 (Multi-Head Attention)

多头注意力是在标准注意力机制的基础上，将注意力分成多个头来并行计算，以捕捉不同的表示子空间。其计算公式为：

MultiHead(Q,K,V)=Concat(head1,…,headh)WO\text{MultiHead}(Q, K, V) = \text{Concat}(\text{head}_1, \ldots, \text{head}_h)W^O MultiHead(Q,K,V)=Concat(head1​,…,headh​)WO

其中每个头的计算为：

headi=Attention(QWiQ,KWiK,VWiV)\text{head}_i = \text{Attention}(QW_i^Q, KW_i^K, VW_i^V) headi​=Attention(QWiQ​,KWiK​,VWiV​)

通俗理解语法，语义这样多层注意。

# 3.3 自注意力层 (Self-Attention Layer)

在自注意力层中，Query、Key和Value都是来自同一输入序列。其实现步骤如下：

  1. QKV投影：将输入 hidden_states 通过三个线性层 q_proj, k_proj, v_proj 投影为 Q, K, V 三个矩阵。
  2. 形状变换：将 Q, K, V 张量重塑为多头格式 [batch, num_heads, seq_len, head_dim]。其中 head_dim * num_heads = d_model。
  3. 进行注意力计算：计算注意力分数，并应用 mask 和 softmax 函数。
  4. 输出投影：将注意力输出重塑为 [batch, seq_len, d_model]，并通过输出投影层 o_proj。

# 3.4 分组查询注意力 (Grouped Query Attention, GQA)

GQA 是一种用于减少 Key Value 数量和 Attention 计算量的优化方法。在 MHA 中，一个 Query Head 对应一个 Key/Value Head，但在 GQA 中，多个 Query Heads 可以共享同一个 Key/Value Head，这样可以显著减少 KV 的数量。

在 Qwen3-8B 中，num_heads=32，num_key_value_heads=8，因此每 4 个 Query Heads 共享 1 个 Key/Value Head。在实际实现中，Key/Value 投影时会将输入维度从 d_model 降低到 num_key_value_heads * head_dim (而不是 num_heads * head_dim)。

在进行注意力计算时，Query Heads 的数量仍然是 num_heads，而 Key/Value Heads 的数量是 num_key_value_heads。因此我们需要通过重复 Key/Value Heads 来匹配 Query Heads 的数量。

# 3.5 RoPE位置编码

RoPE（Rotary Position Embedding）是一种位置编码方法，通过将位置编码与 Query 和 Key 的向量相乘来增强模型对序列位置的感知。其核心思想是将位置编码嵌入到注意力计算中，而不是简单地添加到输入向量中。

RoPE 的计算公式为：

RoPE(x,pos)=x⋅cos⁡(pos)+rot(x)⋅sin⁡(pos)\text{RoPE}(x, pos) = x \cdot \cos(pos) + \text{rot}(x) \cdot \sin(pos) RoPE(x,pos)=x⋅cos(pos)+rot(x)⋅sin(pos)

其中 rot(x) 是对 x 进行旋转操作，pos 是位置编码。

在 Qwen3 中，在进行注意力计算之前，我们会对 Query 和 Key 应用 RoPE 位置编码。具体实现中，使用 apply_rotary_pos_emb 函数来将位置编码应用到 Query 和 Key 上。

Transformer 的输入是一串 token 向量（embedding），但是注意力机制本身 对顺序不敏感：

  • “我爱你”和“你爱我”喂进去，Attention 看的只是向量相似度，没有顺序信息。
  • 所以我们必须想办法告诉模型 “这个词在第几个位置”。

这就是 位置编码（Positional Encoding） 的作用。

# 3.6 RMSNorm

Qwen 3 使用 RMSNorm（Root Mean Square Normalization）来替代传统的 LayerNorm。RMSNorm 的计算公式为：

RMSNorm(x)=xmean(x2)+ϵ⋅γ\text{RMSNorm}(x) = \frac{x}{\sqrt{\text{mean}(x^2) + \epsilon}} \cdot \gamma RMSNorm(x)=mean(x2)+ϵ​x​⋅γ

其中 ϵ\epsilonϵ 是一个小常数，用于防止除零错误，γ\gammaγ 是可学习的缩放参数。

  • 一首歌声音特别大，把你吓一跳；
  • 下一首声音特别小，你听不见；
    你就需要一个“自动音量均衡器”。

归一化（Normalization）的核心思想就是：
把数据的数值范围调整到比较“正常”的区间，让后面的学习更容易。

# 3.7 Q/K Normalization

Qwen 3 引入了 Q/K Normalization，即在计算注意力分数之前，对 Query 和 Key 进行归一化处理。这有助于提高模型的稳定性和收敛速度。

注意这里的 Q/K Normalization 和 LayerNorm 有所不同，它是在 head 维度上进行归一化，而不是在序列维度上。具体实现中，我们会对 Q 和 K 应用 RMSNorm 进行归一化处理。

# 3.8 Qwen 3 Self Attention Layer

在加入了上述优化后，Qwen 3 的 Self Attention Layer 结构如下：

<img src="/assets/图片/attention.png" alt="Qwen 3 Self Attention Layer 架构示意图" style="zoom:33%;" />

  1. 首先输入 hidden_states 分别通过 q_proj, k_proj, v_proj 进行线性投影，得到 Q, K, V。

  2. 对 Q, K, V 进行形状变换，重塑为多头格式。

  3. 对 Q 和 K 应用 RMSNorm 进行归一化处理。

  4. 对 Q 和 K 应用 RoPE 位置编码。

  5. 根据 GQA 机制对 K 和 V 进行复制，以匹配 Q 的头数。

  6. 进行注意力计算：

    • 计算注意力分数 (QKTQK^TQKT)、应用 scale (1dk\frac{1}{\sqrt{d_k}}dk​​1​)，mask 和 softmax。
    • 计算注意力输出 (softmax结果乘以 V)。

  7. 将注意力输出通过输出投影层 o_proj，得到最终的输出。

举例处理过程：我爱你

首先经过分词：分成我爱你

然后进行查找，在一个训练时就确定好的固定的词表中查找每个 token 的 ID 。

[我] → 101
[爱] → 202
[你] → 303

每个 token 会查词表 embedding，变成一个向量

在模型里有一个 embedding 矩阵，可以想象成一个“大字典表”：

  • 形状是 [词表大小, d_model]
  • 假设词表大小 = 100,000，d_model = 4096
  • 那就是一个 [100000, 4096] 的矩阵

这个矩阵的大小：[vocab_size,d_model]

  • vocab_size = 词表的大小（也就是 token 的总数，比如 50,000 或 150,000）（也就是词的个数）
  • d_model = 每个词向量的维度（比如 4096）

对应查找第101、202、303行，可以得到对应的向量

"我" → [0.12, -0.08, 0.33, ..., 0.45]  (长度 4096)
"爱" → [0.02,  0.88, -0.19, ..., 0.03] (长度 4096)
"你" → [0.15, -0.67,  0.21, ..., -0.42] (长度 4096)

把他们拼成矩阵，得到hidden_states: [3, 4096] # 3个词，每个词4096维向量

这些 token 向量堆起来，就得到了 hidden_states，形状一般是：[batch_size,seq_len,d_model]

  • batch_size：一次输入多少个句子（比如一次喂 32 条）
  • seq_len：每个句子有多少个 token（比如句子长 10 个词 → seq_len = 10）
  • d_model：每个 token 被 embedding 成多长的向量（比如 4096）

hidden_states 就是 Transformer 某一层的输入。

q_proj / k_proj / v_proj 是什么

它们是三组 线性变换（矩阵乘法 + 偏置），即三个小的全连接层（linear layer）：

  • q_proj：把 hidden_states 转成 Query 矩阵 Q
  • k_proj：把 hidden_states 转成 Key 矩阵 K
  • v_proj：把 hidden_states 转成 Value 矩阵 V

公式可以写成：

Q=hidden_states⋅WQ,K=hidden_states⋅WK,V=hidden_states⋅WVQ = \text{hidden\_states} \cdot W_Q, \quad K = \text{hidden\_states} \cdot W_K, \quad V = \text{hidden\_states} \cdot W_V Q=hidden_states⋅WQ​,K=hidden_states⋅WK​,V=hidden_states⋅WV​

其中 WQ,WK,WVW_Q, W_K, W_VWQ​,WK​,WV​ 是训练出来的参数矩阵。

想象一场会议：

  • 每个人的 hidden_states 就是“他本来的发言稿”。
  • q_proj 就是把发言稿转成“我的问题”。
  • k_proj 就是把发言稿转成“我的标签（别人能不能找到我）”。
  • v_proj 就是把发言稿转成“我的具体内容”。

这样：

  • 你问问题（Q），
  • 看谁的标签（K）和你最相关，
  • 然后把对应的内容（V）收集过来。
 Q = 想问的向量  
 K = 被匹配的标签向量  
 V = 携带的信息向量

# 4 Feed Forward Network (FFN)详解

# 4.1 SwiGLU激活函数

在理论课上我们介绍过 Sigmoid, Tanh 和 ReLU 等常见激活函数。而在 Qwen 3 使用了 SwiGLU 激活函数，它结合了 SiLU 和 GLU 的优点，能够更好地捕捉非线性关系。

SiLU (Sigmoid Linear Unit) 是 Sigmoid 和 ReLU 的改进版，其公式为：

SiLU(x)=x⋅Sigmoid(x)\text{SiLU}(x) = x \cdot \text{Sigmoid}(x) SiLU(x)=x⋅Sigmoid(x)

GLU (Gated Linear Unit) 是一个门控机制，他的核心思想是通过一个范围在 [0, 1] 的门控函数来控制信息的流动。GLU 的公式为：

GLU(x)=σ(Wgx)⊙(Wxx)\text{GLU}(x) = \sigma(W_g x) \odot (W_x x) GLU(x)=σ(Wg​x)⊙(Wx​x)

其中 σ\sigmaσ 是范围为 [0,1] 的激活函数，WgW_gWg​ 和 WxW_xWx​ 是可学习的权重矩阵，⊙\odot⊙ 表示逐元素乘法。

SwiGLU 是 σ=SiLU\sigma = \text{SiLU}σ=SiLU 的 GLU 变体，其公式为：

SwiGLU(x)=SiLU(Wgx)⊙(Wxx)\text{SwiGLU}(x) = \text{SiLU}(W_g x) \odot (W_x x) SwiGLU(x)=SiLU(Wg​x)⊙(Wx​x)

# 4.2 FFN 结构

标准的前馈神经网络 (FFN) 由两个线性层和一个激活函数组成，可以表示为：

FFN(x)=W2⋅σ(W1⋅x+b1)+b2\text{FFN}(x) = W_2 \cdot \sigma(W_1 \cdot x + b_1) + b_2 FFN(x)=W2​⋅σ(W1​⋅x+b1​)+b2​

其中 W1W_1W1​ 和 W2W_2W2​ 是可学习的权重矩阵，b1b_1b1​ 和 b2b_2b2​ 是偏置项，σ\sigmaσ 是激活函数。

# Qwen 3 FFN 结构

在 Qwen 3 中，FFN 采用 SwiGLU 作为激活函数，并使用 intermediate_size 作为中间层的维度。

包含三个线性层：

  1. 门控投影 (Gate Projection)：计算门控值，形状为 [batch, seq_len, intermediate_size]。
  2. 上投影 (Up Projection)：计算上投影值，形状为 [batch, seq_len, intermediate_size]。
  3. 下投影 (Down Projection)：将结果投影回原维度，形状为 [batch, seq_len, hidden_size]。

# 旅程开始：从文字到数字

# 第 1 步：分词 (Tokenization) - “查字典”

  • 你输入： “我爱你”
  • Qwen3 的 Tokenizer (字典管理员)： 它有一本巨大的、预先训练好的词典（vocab_size = 151,936）。它会把你的输入切分成它认识的基本单位。

    • “爱” -> 查字典 -> 找到 ID 202
    • “你” -> 查字典 -> 找到 ID 303
  • 输出： 一个整数序列 [101, 202, 303]。现在，模型终于能“读”你的输入了。

# 第 2 步：嵌入 (Embedding) - “赋予初始含义”

  • 输入： [101, 202, 303]
  • Qwen3 的 Embedding Layer (概念转换师)： 它内部有一个巨大的参数矩阵，像一个知识库，尺寸为 [151936, 4096]。
    • 它取出第 101 行，这是一个 4096 维的向量，代表“我”的初始语义。
    • 它取出第 202 行，这是代表“爱”的初始语义的向量。
    • 它取出第 303 行，这是代表“你”的初始语义的向量。
  • 输出： 一个形状为 [3, 4096] 的矩阵（我们称之为 hidden_states）。这 3 行 4096 列的数字，就是“我爱你”这句话的初始“思想快照”。
    • hidden_states = [[0.1, 0.8, ...], # “我”的向量
    • [-0.5, 0.2, ...], # “爱”的向量
    • [0.9, -0.1, ...]] # “你”的向量

# 核心处理：36 层解码器 (Decoder Layers) - “深度思考的流水线”

现在，这个 [3, 4096] 的思想快照将进入一个有 36 个车间的深度加工流水线。每个车间就是一个 Decoder Layer。我们只看第一个车间里发生了什么，后面的 35 个车间工作流程完全一样。

# 车间 1 / 36：

这个 hidden_states 矩阵被送了进来。车间里有两个主要工序：Self-Attention 和 FFN。

# 工序 A: 自注意力层 (Self-Attention) - “开一场关系研讨会”

这是最关键的一步，目的是让“我”、“爱”、“你”这三个独立的向量互相交流，理解彼此之间的关系。

  1. 准备材料 (QKV 投影):

    • 原始的 hidden_states 矩阵被复制三份，分别乘以三个不同的“任务权重矩阵”(q_proj, k_proj, v_proj)，生成三个新矩阵：Query (Q), Key (K), 和 Value (V)。
    • Q (查询): 代表“我这个词想了解什么？” (例如，“你”的 Q 向量可能在问：“谁是动作的承受者？”)
    • K (键): 代表“我这个词有什么特征？” (例如，“你”的 K 向量会表明：“我是一个代词，可以作为宾语。”)
    • V (值): 代表“我这个词的实际内容是什么？” (例如，“你”的 V 向量包含了“你”的完整语义。)

  2. 增强信息 (RoPE & Q/K Norm):

    • RoPE 位置编码： 在计算前，Q 和 K 向量会被“旋转”一下。这个旋转的角度取决于词的位置（“我”在第1位，“爱”在第2位，“你”在第3位）。这样一来，模型就能感知到词的顺序。
    • Q/K 归一化： 对 Q 和 K 向量进行一次 RMSNorm，像调整音量一样，让数值稳定，防止计算时出现极端值。

  3. 分组讨论 (GQA - Grouped Query Attention):

    • 模型有 32 个注意力头（想象成 32 个并行的讨论组），但为了省事（减少计算量），它只准备了 8 组 K 和 V。
    • 这 8 组 K 和 V 会被复制，供 32 个 Q 讨论组使用（每 4 个 Q 组共享 1 组 K/V）。这就好比 32 个提问者，去咨询 8 位专家，有些专家需要同时回答 4 个人的问题。

  4. 计算关系得分 (Attention Score):

    • 现在开始正式讨论！以“你”这个词为例，它的 Q 向量会分别和“我”、“爱”、“你”的 K 向量做点积运算，得到一个亲密度分数。
    • Score(“你” -> “我”) = Q(你) · K(我) -> 分数可能不高
    • Score(“你” -> “爱”) = Q(你) · K(爱) -> 分数会很高，因为“爱”直接作用于“你”
    • Score(“你” -> “你”) = Q(你) · K(你) -> 分数也会很高，关注自身
    • 因果掩码 (Causal Mask): 在生成任务中，一个词只能关注它自己和它前面的词。所以这里的计算是合规的。如果是预测“爱”，它就不能看到“你”的信息。

  5. 加权融合 (Weighted Sum):

    • 将这些分数通过 softmax 函数转换成权重（总和为1）。比如，“你”的注意力权重可能是：[对“我”0.1, 对“爱”0.6, 对“你”0.3]。
    • 用这些权重去对所有词的 V 向量进行加权求和。
    • 新的“你”向量 = 0.1 * V(我) + 0.6 * V(爱) + 0.3 * V(你)
  • 输出： 经过这一轮研讨会，我们得到了一个新的 hidden_states 矩阵。现在，每个词的向量都融合了上下文信息。“你”的向量不再是孤立的“你”，而是“那个被我所爱的你”，它的向量表示已经吸收了主谓宾的语法结构信息。
# 工序 B: 前馈网络 (FFN) - “独立消化和深度思考”

刚刚开完了大会，信息量很大。现在每个词的向量需要“回到自己的办公室”独立思考一下。

  1. 信息扩展 (Up Projection & Gate Projection):
    • 每个 4096 维的向量会被两个不同的线性层（gate_proj 和 up_proj）分别映射到 12288 维。我们得到了一个“门控”向量和一个“数据”向量。
  2. 门控过滤 (SwiGLU):
    • “门控”向量经过 SiLU 激活函数，变成一个 0 到 1 之间的“过滤器”。
    • 这个“过滤器”会和“数据”向量相乘，决定哪些信息是重要的，应该被保留；哪些是次要的，可以被削弱。这是一种非常高效的信息筛选机制。
  3. 信息压缩 (Down Projection):
    • 经过筛选的 12288 维向量，再通过一个线性层 (down_proj) 压缩回 4096 维。
  • 输出： 经过 FFN，每个向量在融合了上下文之后，又进行了一次深度的、非线性的自我加工。信息的表示变得更加丰富和复杂。

（别忘了：RMSNorm 和残差连接）

在 Self-Attention 和 FFN 这两大工序前后，都有 RMSNorm（质检员，稳定数据）和残差连接（安全绳，把输入直接加到输出上，防止信息在深层网络中丢失）。

循环往复 35 次...

这个 [3, 4096] 的矩阵会继续进入第 2、第 3、...、直到第 36 个车间，重复上述的“开会”+“思考”过程。每经过一层，向量对“我爱你”这句话的理解就深刻一分。

# 最终预测：从思想到文字

# 第 4 步：输出层 (Output Layer) - “做出预言”

  • 输入： 经过 36 层加工后，我们得到了最终的 hidden_states 矩阵。我们只关心**最后一个词（“你”）**的最终向量，因为它包含了对整个句子的理解，最适合用来预测下一个词。
  • Qwen3 的 Output Layer (预言家)：
    • 它将这个 4096 维的“你”的最终向量，乘以一个巨大的 [4096, 151936] 的权重矩阵（通常和 Embedding 矩阵共享权重）。
    • 输出： 一个 151936 维的超长向量，我们称之为 logits。这个向量的每一个位置，都对应着词典里的一个词。上面的数值代表模型认为下一个词是它的“可能性得分”。

# 第 5 步：生成文本 (Text Generation) - “宣布答案”

  • 输入： logits 向量。
  • Softmax 函数： 将这 151,936 个得分转换成一个概率分布（所有概率加起来等于1）。
    • 可能 P(下一个词是“。”) = 0.85
    • 可能 P(下一个词是“吗”) = 0.05
    • 可能 P(下一个词是“的”) = 0.03
    • ...
  • 采样 (Sampling)： 模型根据这个概率分布选择一个词。最简单的方式是选择概率最高的那个词（贪心策略）。
  • 最终输出： 模型选择了 “。”。

然后，故事继续...

模型会把新生成的“。”拼接到输入后面，形成新的序列“我爱你。”，然后把这个新序列再次完整地走一遍上面的所有流程，来预测下一个词，周而复始，直到生成结束符或者达到最大长度。

这就是 Qwen3-8B 处理“我爱你”并生成后续文本的完整运作流程！希望这个旅程足够直观和详细！

好的，我们来逐行、逐块地详细拆解这段代码。这段代码可以说是 Transformer 模型的心脏——一个完整的解码器层（Decoder Layer）。

我们还是用之前那个“信息深度加工车间”的比喻来理解它。Qwen3DecoderLayer 这个类，就是定义了一个标准化的车间。

# 1. __init__ 方法：车间的建造和设备安装

这个方法在创建 Qwen3DecoderLayer 对象时被调用，它的作用是把这个车间所需要的所有设备（也就是神经网络模块）都预先准备好、安装到位。

class Qwen3DecoderLayer(nn.Module):
    def __init__(
        self,
        config: Qwen3Config,
        layer_idx: int,
        device: Optional[str] = None,
        dtype: Optional[torch.dtype] = None,
    ):
        super().__init__()
        self.hidden_size = config.hidden_size

        # ... (device 和 dtype 的设置)

        # ------------------- 安装核心设备 -------------------

        # 1. 安装“集体讨论会”设备 (Self-Attention)
        self.self_attn = Qwen3Attention(...)

        # 2. 安装“专家独立思考”设备 (Feed-Forward Network)
        self.mlp = Qwen3MLP(...)

        # 3. 安装两个“质检站” (RMSNorm)
        self.input_layernorm = RMSNorm(...)
        self.post_attention_layernorm = RMSNorm(...)

逐句解释：

  • class Qwen3DecoderLayer(nn.Module):
    • 定义一个名为 Qwen3DecoderLayer 的类，它继承自 PyTorch 的 nn.Module。这是所有神经网络模块的基类，继承它可以让我们的类自动获得参数管理、GPU 移动等能力。
  • def __init__(...):
    • 构造函数。config 是一个包含模型所有超参数（如 hidden_size, num_heads 等）的配置对象。layer_idx 是当前是第几个车间（例如，从 0 到 35）。
  • super().__init__()
    • 调用父类 nn.Module 的构造函数，这是 PyTorch 的标准写法。
  • self.self_attn = Qwen3Attention(...)
    • 核心设备一：自注意力模块。这里实例化了一个 Qwen3Attention 对象，并命名为 self.self_attn。这个对象里面包含了所有与注意力计算相关的逻辑，比如 QKV 投影、RoPE、GQA 等。你可以把它想象成车间里那套复杂的“集体讨论”会议系统。
  • self.mlp = Qwen3MLP(...)
    • 核心设备二：前馈网络模块。这里实例化了一个 Qwen3MLP 对象，命名为 self.mlp。它内部包含了 SwiGLU 激活函数和那三个线性投影层。这就是车间里每个工位的“独立思考”处理器。
  • self.input_layernorm = RMSNorm(...)
    • 质检站一。这个 RMSNorm 层被安装在进入注意力模块之前。它的作用是稳定输入数据。
  • self.post_attention_layernorm = RMSNorm(...)
    • 质检站二。这个 RMSNorm 层被安装在注意力模块之后、进入前馈网络之前。它负责稳定注意力模块的输出。

总结 __init__： 到这里，一个功能齐全的“车间”就建造好了。里面有注意力设备、前馈网络设备，以及两个质检站，随时准备接收数据进行加工。

# 2. forward 方法：车间的实际工作流水线

这个方法定义了数据（hidden_states）进入这个车间后，会按照什么样的顺序流经各个设备。这是整个模块的动态执行逻辑。

    def forward(
        self,
        hidden_states: torch.Tensor,
        attention_mask: Optional[torch.Tensor] = None,
    ) -> torch.Tensor:
  • def forward(...)：定义了前向传播的过程。
  • hidden_states: torch.Tensor: 这是输入的“原材料”，一个形状为 [batch_size, seq_len, hidden_size] 的张量。比如对于“我爱你”，它就是 [1, 3, 4096]。
  • attention_mask: 这是可选的“指令单”，告诉注意力机制哪些 token 之间不能互相“看到”。对于生成任务，这就是因果掩码。

流水线开始：

        # 步骤 1: “安全绳” - 保存原始输入
        residual = hidden_states
  • residual = hidden_states：创建一个“直通车”或“安全绳”。我们先把最原始的输入 hidden_states 备份一份到 residual 变量里。这是为了后面的残差连接（Residual Connection）。

# 第一个加工区：注意力模块

        # 步骤 2: “进门质检”
        hidden_states = self.input_layernorm(hidden_states)

        # 步骤 3: “集体讨论会”
        hidden_states = self.self_attn(
            hidden_states=hidden_states,
            attention_mask=attention_mask,
        )

        # 步骤 4: “信息融合” - 将讨论结果与原始信息相加
        hidden_states = residual + hidden_states
  • hidden_states = self.input_layernorm(hidden_states)：
    • 原材料先经过第一个质检站 self.input_layernorm 进行归一化。
  • hidden_states = self.self_attn(...)：
    • 经过质检的数据被送入 self.self_attn 这个复杂的注意力设备中。在 Qwen3Attention 内部，会完成 QKV 投影、RoPE、GQA、注意力分数计算等所有操作。
    • 输出的 hidden_states 已经是融合了上下文信息的新向量了。
  • hidden_states = residual + hidden_states：
    • 关键的残差连接！ 将注意力模块的输出，与我们一开始备份的原始输入 residual 逐元素相加。
    • 为什么这么做？ 这样可以确保即使注意力模块没学好（比如输出全是 0），原始信息也能通过这条“直通车”传递下去，避免了在深层网络中信息丢失的问题，让训练更稳定。

# 第二个加工区：前馈网络模块

        # 步骤 5: 更新“安全绳”，为下一次残差连接做准备
        residual = hidden_states

        # 步骤 6: “二次质检”
        hidden_states = self.post_attention_layernorm(hidden_states)

        # 步骤 7: “专家独立思考”
        hidden_states = self.mlp(hidden_states)

        # 步骤 8: “二次信息融合”
        hidden_states = residual + hidden_states
  • residual = hidden_states：
    • 流水线进行到一半，我们把当前的结果（经过注意力模块和第一次残差连接后的 hidden_states）再次备份到 residual 变量中。
  • hidden_states = self.post_attention_layernorm(hidden_states)：
    • 数据在进入 FFN 之前，先经过第二个质检站 self.post_attention_layernorm 进行归一化。
  • hidden_states = self.mlp(hidden_states)：
    • 经过质检的数据被送入 self.mlp 设备。在 Qwen3MLP 内部，会完成信息扩展、SwiGLU 门控过滤和信息压缩等操作。
    • 输出的 hidden_states 是经过深度加工和非线性变换的、信息表示更丰富的向量。
  • hidden_states = residual + hidden_states：
    • 第二次残差连接！ 将 FFN 模块的输出，与进入 FFN 之前的状态 residual 相加。

# 完成加工，出车间

        return hidden_states
  • return hidden_states：返回经过一个完整车间（一个 Decoder Layer）深度加工后的 hidden_states。这个输出张量的形状和输入完全一样（[batch_size, seq_len, hidden_size]），但其中蕴含的信息已经更加丰富。它将被作为下一个车间（下一层 Decoder Layer）的输入，或者如果是最后一层，就送往最终的输出层。

# 总结（流程图视角）

            Input: hidden_states (来自上一层)
                   |
                   |------> residual (备份1)
                   |
            [ RMSNorm (input_layernorm) ]
                   |
            [ Self-Attention (self_attn) ]
                   |
                   +-------> (+) <------- residual (备份1)
                   |
            hidden_states' (融合上下文)
                   |
                   |------> residual (备份2)
                   |
            [ RMSNorm (post_attention_layernorm) ]
                   |
            [ FFN (mlp) ]
                   |
                   +-------> (+) <------- residual (备份2)
                   |
            Output: hidden_states'' (送往下一层)

这段代码完美地实现了 Transformer Decoder 层的标准结构：Pre-Norm（先归一化再进子模块）+ 残差连接。每个模块各司其职，共同完成对输入信息的一次提炼和升华。
