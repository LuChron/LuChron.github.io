# AVL Trees, Splay Trees and Amortized Analysis

在 FDS 的学习中，我们知道：对一棵二叉查找树进行多次增删操作，有可能破坏二叉树的平衡性，从而降低查找效率。最糟糕的情况是将一组节点按照升 / 降序插入，这样的话二叉树就会退化成一个链表，访问节点的时间复杂度相应地从 O(log⁡N) 降到 O(N)。

为了提升二叉查找树的查找效率，我们需要保证整棵树的平衡性，AVL 树（以及后面要讲的伸展树）便是不错的解决之道。

什么是 balanced trees？

  • 空的二叉树被认为是平衡的
  • 如果树 TTT 有左右子树 TLT_LTL​ 和 TRT_RTR​，那么满足下列条件的树 TTT 才是平衡的：
    • TLT_LTL​ 和 TRT_RTR​ 是平衡的
    • ∣hL−hR∣≤1|h_L - h_R| \le 1∣hL​−hR​∣≤1，其中 hLh_LhL​ 和 hRh_RhR​ 分别是 TLT_LTL​ 和 TRT_RTR​ 的高度

对于树中的每一个节点，其左子树和右子树的高度差的绝对值不能超过 1。

AVL树的每个节点都有一个平衡因子(balance factor)BF(node)=hL−hRBF(node) = h_L - h_RBF(node)=hL​−hR​。根据上面的定义知，它的取值仅有-1, 0或1。

# 摊还分析

# 1. 势能函数 Φ(x) 的本质

  • Φ(x) 是一个函数，用来表示系统当前的“潜在能量”或者“储备”。
  • 系统状态不同，势能不同。
  • 在摊还分析里，我们把摊还成本定义为：

c^i=ci+(Φ(操作后)−Φ(操作前))\hat{c}_i = c_i + (\Phi(\text{操作后}) - \Phi(\text{操作前})) c^i​=ci​+(Φ(操作后)−Φ(操作前))

这里：

  • cic_ici​ = 实际花费（操作次数）
  • Φ(操作后)−Φ(操作前)\Phi(\text{操作后}) - \Phi(\text{操作前})Φ(操作后)−Φ(操作前) = 势能变化

# 2. 特性 1：开销大的操作应让势能下降

开销大的操作应当倾向让势能降

解释：

  • 当某次操作花费很大时（比如动态数组扩容，搬很多元素），我们希望摊还成本不超过平均值。
  • 如果势能在这次操作中下降很多（ΔΦ < 0），势能的下降可以“抵消”这次大花费。

比喻：

  • 你有一个储蓄罐（势能）
  • 这次要花大钱 → 打开储蓄罐用钱 → 摊还成本看起来就没那么高

# 3. 特性 2：开销小的操作应让势能升

开销小的操作应当倾向让势能升

解释：

  • 当操作本身很便宜（插入一个元素，cost = 1），我们可以增加势能（ΔΦ > 0），为将来可能出现的大开销存钱。

比喻：

  • 小操作 = 花很少的钱 → 顺便存一点钱到储蓄罐
  • 以后遇到扩容时就用这些钱

# 4. 特性 3：Φ(final) > Φ(initial)

势能最终要高于初始势能

解释：

  • 如果系统结束时势能低于初始值，说明我们把之前“存的钱”全部花掉了。
  • 对摊还分析来说，这保证了摊还成本总和 ≥ 实际成本总和，公式如下：

∑c^i=∑ci+(Φfinal−Φinitial)\sum \hat{c}_i = \sum c_i + (\Phi_\text{final} - \Phi_\text{initial}) ∑c^i​=∑ci​+(Φfinal​−Φinitial​)

  • 如果 Φ(final) ≥ Φ(initial) → 总摊还成本 ≥ 总实际成本 → 分配是合理的

比喻：

  • 储蓄罐最终钱没透支，说明我们存的钱足够支付高成本操作

# 红黑树

在红黑树中，「叶子节点」特别指的是空节点 (nil)，不要搞错啦！（下面介绍定义的时候还会提到这一点的）

红黑树(red-black trees) 本质上也是一棵二叉查找树，它的目标同 AVL 树一样，也是尽可能地维护二叉查找树的平衡。下图表示的是红黑树的一个节点：

  • 节点除了有指向左右孩子的指针外，还额外多了一个指向父节点的指针
  • 此外又多了一个存储颜色的字段，占 1 bit 空间（红色 / 黑色）
  • 红黑树里的空指针NULL一般会称为NIL，它代表的是一个外部节点，其颜色为黑色。规定：红黑树的孩子要么是实际存在的节点，要么是个空节点

如果一个节点是红色的，那么它的孩子都是黑色的

  • 总结：红色节点要么有两个黑孩子，要么没有孩子，不会出现红色节点相邻的情况，也不会出现红色节点只有一个孩子的情况（否则下面的性质不会满足）

  • 在红黑树中，实际存在的节点被称为内部节点(internal node)，而空节点NIL被称为外部节点(external node)

    对于每个节点，从该节点出发，到它后代叶子节点（即NIL节点）的所有简单路径包含了相同数量的黑色节点（这是实现红黑树平衡的关键）

为了量化红黑树的平衡程度，我们为节点 x 定义一个称为「黑高」(black height) 的字段 bh(x)bh(x)：它表示从节点 x 出发到**叶子节点 (NIL)**的任意简单路径上黑色节点的个数（不包括节点 x）

  • 根据定义的性质 5，由于每条简单路径的黑色节点数相同，所以便可以任意选取其中 1 条路径
  • 整棵树的黑高等于根节点的黑高

引理：一棵有 NN 个内部节点的红黑树，它的高度至多为 2log⁡(N+1)2log(N+1)。
