# 1 预备知识

操作系统（OS）是管理计算机硬件、软件资源和为计算机程序提供通用服务的系统软件。操作系统是计算机系统软件的重要组成部分。

内核是一个计算机程序，它是计算机操作系统的核心，对系统中的所有内容都有完全的控制权。它是操作系统的“最低”级别。

cat test_?.txt #简化操作

less test.txt #分页查看文件内容

mkdir -p 是一个用于创建目录的命令，常见于类 Unix 操作系统（如 Linux 和 macOS）中的命令行。

具体来说：

  • mkdir 命令用于创建一个新的目录。
  • -p 选项的作用是递归创建目录。当你使用 -p 时，如果中间的目录路径不存在，mkdir 会自动创建它们，而不会报错。

举个例子：

mkdir -p /home/user/docs/project

这条命令会创建 /home/user/docs/project 这个目录。如果 /home/user 或 /home/user/docs 目录不存在，它们会被自动创建出来。没有 -p 选项的话，如果中间的某个目录不存在，mkdir 会报错。

# 1.3 SSH

SSH 的全称是 Secure Shell (安全外壳协议)，它是一种网络协议，用于在不安全的网络上安全地运行网络服务。简单来说，SSH 让你能够安全地远程连接和控制另一台计算机。

想象一下，你想在另一台电脑上执行命令、传输文件，或者管理服务器，但你和那台电脑之间隔着互联网这个“不安全”的公共场所。SSH 就像是为你和那台电脑之间建立了一条加密的、安全的“隧道”，确保你们之间的通信内容不会被窃听或篡改。

什么是非对称加密？

非对称加密，也称为公钥加密，与对称加密（例如 AES）不同，它使用一对密钥：

  • 公钥 (Public Key): 可以公开分发，任何人都可以获取。用公钥加密的数据，只有对应的私钥才能解密。
  • 私钥 (Private Key): 必须严格保密，只有密钥的拥有者持有。用私钥签名（或解密公钥加密的数据）的数据，可以用对应的公钥来验证（或解密）。

# 1.4 用户与组

Linux 的用户：

Linux是一个多用户多任务的操作系统，每个用户都需要一个账户才能登录系统并使用系统的资源。

Linux中的用户账户可以分为很多类：常用的 普通用户和超级 用户。普通用户只能访问自己拥有或被赋予权限的资源，超级用户（root）拥有对所有系统资源的完全访问权限。

Linux 用户组：

除了用户账户外，Linux 还支持用户组的概念。用户组是具有相同特性的用户的集合。用户可以属于多个用户组，每个用户组都有一个唯一的组 ID（GID）。

用户组的主要作用是用于控制用户对文件和目录的访问权限。当用户创建一个文件或目录时，可以指定该文件或目录的所有者、所有组和其他组。所有者拥有对该文件或目录的完全访问权限，所有组的成员拥有对该文件或目录的读写权限，其他组的成员则只能读取该文件或目录。

# 1.5 计算机集群

所谓计算机集群，就是将多台计算机连接在一起，通过网络协同工作，以完成一些大规模的计算任务。为什么我们需要计算机集群呢？因为单体的制造成本和性能是有限的。制造芯片时，人们想把单个处理器的性能提升到极致，但是遇到了物理限制：一块集成电路上的晶体管数量越多，设计就越复杂，发热就越严重，功耗就越大，性能就越低。因此，人们开始尝试将多个处理器连接在一起，就有了现代多核处理器。制造计算机时，也可以放置多个 CPU（常见的服务器一般都具有两颗），但放置更多只会增加单台计算机的设计和制造难度。与其想着怎么把单体造强，不如想着怎么把多个单体连接在一起，怎么让它们协同工作，这就是并行计算思想的由来。

# 1.6 MPI

MPI 指的是Message Passing Interface，是程序在不同机器间发送、接收数据的接口标准，类似于定义了一套通信的 API。它被设计用于支持并行计算系统的架构，使得开发者能够方便地开发可移植的消息传递程序。MPI 编程能力在高性能计算的实践与学习中也是非常基础的技能。
